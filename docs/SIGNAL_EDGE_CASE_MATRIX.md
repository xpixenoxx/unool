# Unool Signal — Edge-Case & Resilience Matrix

**Version:** 1.0  
Applies to `signalEngine.ts`, `normalize.ts`, `syncEngagement.ts`, `/api/signal/**`, and `/dashboard/signal`.

| Case ID | Scenario | Expected Backend / Engine Behavior | Expected UI Behavior |
|---|---|---|---|
| **EC-01** | **New workspace, 0 connected accounts, 0 posts** | Returns `posts: []`, empty KPIs (`null` rates/deltas), `syncHealth: { status: 'no_accounts' }`, `connectedAccounts: []`. | Clean First-Time Welcome state with Connect Accounts (`/onboarding/connect`) & Studio (`/dashboard/studio`) CTAs; zero empty black canvases or `-100%` fake deltas. |
| **EC-02** | **Connected account(s), 0 published posts (only drafts/scheduled)** | Published KPIs = `0` (`publishedCount: 0`, `weightedEngagementRate: null`, `mediaLiftPct: null`, `resonanceScore: null`); Operational queue counts accurately reflect `draftCount` / `scheduledCount`. | Overview shows queue summary + "Publish your first post to unlock resonance trends"; Content & Hooks defaults/prompts to scheduled/drafts filter pill cleanly. |
| **EC-03** | **Posts < 48h old with zero metrics yet (`Golden Hour`)** | `syncEngagement` prioritizes posts with `views + total === 0` or `< 48h` age; sets `syncStatus: 'pending' \| 'synced'`. | Displays `Golden Hour` badge (calculated from `publishedAt ?? createdAt`) and `"Initial metrics syncing from platform APIs"` without framing `0` as permanent failure. |
| **EC-04** | **Publish-only channel (`Discord`, `Telegram`, `Slack`, `Medium`, `Manual`, `Twitch`, `Kick`, `Skool`, `Whop`, `Nostr`, `Warpcast`)** | Sync skips external readback cleanly, marks `sync_status: 'unsupported'`; `views = null`, excluded from Engagement Rate denominator. | Card & Channels table show `N/A (Platform API)` badge with `"This channel does not expose post metrics via API"` tooltip rather than `0`. |
| **EC-05** | **Engagement-only channel (`LinkedIn w_member_social`, `Bluesky`, `Mastodon`, `Reddit`, `Lemmy`, `MeWe`)** | Collects `likes`/`comments`/`shares` into `totalEngagements`; keeps `views = null` (unless API actually returned `views > 0`); excluded from `weightedEngagementRate` numerator AND denominator. | Interactions render normally; Views column shows `N/A (API limit)` with link to `/analytics/linkedin` where applicable. |
| **EC-06** | **Viral outlier post (e.g., 1 post = 5,000 interactions, 9 posts = 10)** | Computes BOTH `avgEngagementsPerPost` and `medianEngagementsPerPost`; includes sample count `n` & confidence badge. | Displays Median alongside Average on Content & Hook summaries so creators aren't misled by 1 anomaly. |
| **EC-07** | **Multi-account on same platform (2 Instagram or 2 LinkedIn accounts)** | Variants keyed strictly by `variant.id` & `platform_account_id`; channel summary groups by `(platform, platformAccountId, accountLabel)` and platform total; filters support account selection. | Every variant pill renders (`@acct1`, `@acct2`) — zero dedup dropping secondary accounts. |
| **EC-08** | **Published variant missing remote `platform_url`** | `variant.status === 'published'` with `!variant.platformUrl` does NOT masquerade as `'publishing'`. | Shows `"Published (link unavailable)"` pill instead of spinning `"Publishing to..."`. |
| **EC-09** | **Post failed (`failed`) or partially failed (2/3 platforms ok, 1 error)** | `/api/signal/posts` & `/api/signal/analytics` include `failed` & `publishing` statuses; error strings sanitized against leaked tokens. | Operational Alert Banner highlights partial/full failure; Inspector shows sanitized error + Retry / Reconnect CTA. |
| **EC-10** | **Upstream API `401` expired token or `429` rate limit during sync** | `syncEngagement` attempts refresh on expiring OAuth; if `401`/`429` persists, preserves prior persisted `platform_posts.engagement` counters untouched, records `sync_status` (`token_expired` / `rate_limited`), continues syncing remaining platforms. | Sync bar shows non-blocking warning naming affected platform + `"Reconnect"` link, NEVER resetting saved counts to `0`. |
| **EC-11** | **Non-UTC User Timezone (`Asia/Kolkata +05:30`, `America/Los_Angeles -07:00`)** | `signalEngine` validates IANA TZ string (safe `'UTC'` fallback if malformed) and formats `variant.publishedAt ?? post.publishedAt ?? post.createdAt` using `Intl.DateTimeFormat`. | Timing heatmap shifts accurately into user's chosen timezone; displays timezone pill explicitly (`Times in Asia/Kolkata`). |
| **EC-12** | **Historical `posts` rows missing `hook_type` / `word_count` / `has_media`** | DB migration backfills `word_count`/`has_media`, AND `signalEngine` runs deterministic `classifyHookType` + word count runtime fallback on `post.content` when columns are null. | Zero `"unknown"` black-hole scatters or zeroed media comparisons. |
| **EC-13** | **Plan retention clamp (`Spark 30d` user selects `90d` or `365d`)** | Server reads `plan.limits.analytics_retention_days`, clamps query lookback window cleanly, returns `truncatedByPlan: true`, `retentionDays`. | UI displays clear retention notice badge (`Spark includes 30-day history · Upgrade for 90d–Unlimited`) instead of pretending 90 days have zero posts. |
| **EC-14** | **Plan-gated CSV export (`Spark`/`Creator` vs `Pro`/`Studio`)** | `GET /api/signal/export` enforces `enforcePlanLimits(workspaceId, 'csv_export')` -> returns `403` JSON with `code: 'PLAN_LIMIT_EXCEEDED'` on Spark/Creator; returns RFC-4180 CSV with formula-injection neutralization (`'`, leading `=,+,-,@` prefixed with `'`) on Pro/Studio. | UI shows lock indicator & Upgrade CTA on CSV button for Spark/Creator, while Printable Summary remains available. |
| **EC-15** | **Cross-tenant / unauthenticated API request / invalid filters** | `getCurrentAuth` + `verifyWorkspaceAccess` enforces `401` / `403`; Zod / strict sanitizer rejects invalid dates or invalid TZ gracefully without 500; invalid filter combinations return clean empty filtered state with `"Reset filters"`. | UI shows friendly filtered empty state with one-click `"Reset all filters"`; switching workspace triggers `clearAllClientCaches()`. |
| **EC-16** | **Full API outage / 500 response on initial fetch** | Returns `{ error }` HTTP 500 JSON cleanly without hanging. | Signal displays crisp Error State Card with `"Retry Load"` button — NEVER renders zeroed KPIs pretending nothing happened. |
| **EC-17** | **Mobile (320px–375px) & Keyboard-Only Navigation** | Same canonical JSON payload. | All tabs/filters wrap cleanly without horizontal page overflow; charts use accessible SVG + clickable/focusable DOM elements & toggleable data tables (zero hover-only canvas traps). |
